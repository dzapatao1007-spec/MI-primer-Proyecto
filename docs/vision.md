# Vision de JARVIS ERP

JARVIS ERP es un sistema de gestión pensado para una empresa de ropa que vende principalmente por Instagram y WhatsApp. Su propósito es ayudar al dueño a ver el negocio con claridad, tomar decisiones más rápidas y controlar operaciones sin perder tiempo en procesos manuales.

El centro del sistema es el Pedido. Todo gira alrededor de la venta: cliente, productos, inventario, proveedores, logística, finanzas, tareas y alertas se relacionan con el pedido para crear una visión completa del negocio.

La empresa opera de forma directa y ágil. Los pedidos llegan desde canales sociales, se gestionan internamente y requieren seguimiento constante para asegurar que cada venta se complete correctamente. El sistema debe ayudar a convertir esa operación diaria en información útil para la toma de decisiones.

El objetivo principal de JARVIS ERP no es solo registrar datos, sino dar claridad al dueño. Debe mostrar lo importante, resaltar problemas, simplificar seguimientos y permitir actuar con mayor confianza.

El diseño del producto debe ser minimalista, limpio y profesional. Cada nueva funcionalidad debe ser simple, útil y escalable, sin añadir complejidad innecesaria.
